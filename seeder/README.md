# Demo mailbox seeder (Apps Script)

Imports 50 **fictional** demo emails (21 phishing in 5 campaigns, 9 suspicious, 20 normal)
into a **test** Gmail inbox, so the add-on and the dashboard have realistic data.

- The emails are generated by `node scripts/buildDemoMailbox.js` from
  `scripts/demoMailboxData.js` into `DemoEmails.gs`.
- Phishing domains end with `.example` (reserved, never real). Their network data is in `fixtures/intel/`.
- Gmail **import** puts them in the inbox; nothing is sent to anyone.
- It is a **separate** Apps Script project, so the add-on never needs the `gmail.insert` permission.

## Run it

1. https://script.google.com (test account) -> New project -> name it `Inbox Detective Seeder`.
2. Project Settings: tick "Show appsscript.json manifest file in editor".
3. Paste `appsscript.json`, and create `Seed.gs` and `DemoEmails.gs` with the content from this folder.
4. Services (+) -> Gmail API -> Add.
5. Choose `importDemoEmails` and click Run. Approve the permissions (select all).
   If it stops in the middle, fix the cause and run it again: it continues where it stopped
   (the `NEXT_INDEX` script property), so no email is imported twice.
6. The log says "Imported 50 demo emails". Refresh Gmail.

**Importing again:** the seeder continues from the script property `NEXT_INDEX`.
To import all 50 again, set `NEXT_INDEX` to `0` and run `importDemoEmails`.

Note: Gmail refuses emails with executable attachments (`.exe`, `.js`, ...). The demo
"malicious attachments" are therefore `.html` files with a double extension
(`invoice.pdf.html`), a technique attackers really use to open fake login pages.
